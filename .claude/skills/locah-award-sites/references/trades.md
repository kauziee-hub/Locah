# Art direction by trade

Starting points, not templates: the concept and seed decide; the owner's words
and pictures decide more. Each entry: what the site must make you *feel*, the
covers that suit, the signature, the range presentation, the conversion path,
the photography brief.

## Restaurant (dine-in / delivery)
Feel: appetite and atmosphere — you can smell it. Covers: `signature` (dishes +
prices beside the plate), `cinematic_zoom`, `window` (noir). Signature: living
photo (gentle steam-like drift), ribbon of dishes. Range: menu chapters with
plates (photo 4:5, name in the display face, price, diet mark), the rest a
refined price list; signature dishes first. Conversion: Order now / Book a
table in the dock; WhatsApp with the dish named. Photos: plated food in
directional light, the room at dusk, hands at the pass — never an empty
dining room. JSON-LD: Restaurant + Menu + servesCuisine + acceptsReservations.

## Bakery / café
Feel: warmth, morning, craft. Covers: `arch`, `signature`, `gallery`. Signature:
ground_morph paper ↔ crust tones, variable type (Fraunces SOFT). Range: plates
for the hero bakes, a board-style list for the daily list; "baked at 7" facts.
Conversion: Order for pickup / call to keep one aside. Photos: crumb texture,
flour on hands, trays coming out — warm grade. JSON-LD: Bakery.

## Butcher / fishmonger
Feel: freshness and trust in the cut. Covers: `signature` (cuts + ₹/kg), `window`
(noir), `stage` (luxury). Signature: living photo (full, cold grade for fish),
contextual cursor "Add". Range: chapters by meat, cuts priced per kg, "cut after
you order" process. Conversion: order by weight, pickup/delivery slots. Photos:
truthful species and cut (the judge's wrong_variety gate), clean counters,
never live animals. JSON-LD: Store (ButcherShop isn't in schema.org → LocalBusiness/Store).

## Gym / fitness
Feel: energy and proof. Covers: `kinetic` (poster faces), `window`, `cinematic_zoom`.
Signature: variable type (Archivo width on scroll), velocity skew. Range:
stacked plan cards with the middle plan featured; class timetable. Conversion:
Book a trial / See plans; WhatsApp to join a plan. Photos: real lifting, chalk,
equipment detail — not models posing. JSON-LD: ExerciseGym/HealthClub.

## Salon / spa / beauty
Feel: refinement, care, transformation. Covers: `stage`, `arch`, `gallery`.
Signature: dissolve (before → after mood), hover image reveal on services.
Range: service menu with duration · price, grouped (Hair / Skin / Bridal).
Conversion: Book an appointment (service → time → details). Photos: hands at
work, textures, products in use; people allowed but the face is not the subject.
JSON-LD: BeautySalon / DaySpa / HairSalon.

## Clinic / care
Feel: calm competence, clarity. Covers: `ledger` (hours/address/phone up front),
`arch`, `stage`. Signature: ground_morph (soft), restraint. Range: services as
type (no empty image frames), doctors with names when given. Conversion: Book a
visit, call; hours always visible. Photos: real clinic rooms, light, never
stock "smiling doctor with clipboard". JSON-LD: MedicalClinic / Dentist /
Physician + openingHoursSpecification.

## Consultant / professional service
Feel: authority through precision. Covers: `ledger`, `window`, `stage`. Signature:
variable type (width), contextual cursor. Range: services as numbered chapters
with outcomes; proof (clients, numbers the owner gave). Conversion: Book a call /
Enquire. JSON-LD: ProfessionalService.

## Retail store
Feel: desire for the object. Covers: `gallery`, `signature` (featured products),
`cinematic_zoom`. Signature: ribbon of products, hover reveal. Range: product
grid with real photos, filters by category, stock honesty. Conversion: Add to
basket → checkout; pickup/delivery. JSON-LD: Store + Product/Offer.

## Architecture / interiors
Feel: space and material. Covers: `depth`, `plane` (8+ photos), `window`.
Signature: zoom-through, dissolve. Range: projects as spotlight rows, not cards.
Conversion: Enquire / Book a site visit / Request a quote. Photos: their own
built work only; monochrome type. JSON-LD: ProfessionalService (+ HomeAndConstructionBusiness).

## Hotel / homestay
Feel: arrival, rest, place. Covers: `cinematic_zoom`, `stage`, `gallery`.
Signature: zoom-through, dissolve. Range: rooms as large rows with what's
included; nearby experiences. Conversion: Check availability (dates in the
dock), WhatsApp. JSON-LD: Hotel / LodgingBusiness + amenityFeature.

## NGO / cause
Feel: people and purpose. Covers: `arch`, `cinematic_zoom`, `gallery`. Signature:
statement read word by word, ground_morph. Range: programmes as stories with
numbers the owner gave. Conversion: Volunteer / Enquire / Donate (only when
giving is live). JSON-LD: NGO + Organization.
