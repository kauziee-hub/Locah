# Visual reference pack

`BRIEF.md` is the founder's visual quality bar (2026-10-17): 15 premium
reference sites and the design principles to extract from each. The
references are a **quality target, not templates to copy**.

The images it names (`ref_01.png` … `ref_15.png`) were not on disk when this
folder was created. Drop them here with exactly those names; the website
certification critic (`platform_testing.certify`) attaches the ones that match
a site's category automatically, and falls back to the written takeaways in
`BRIEF.md` when an image is missing.
